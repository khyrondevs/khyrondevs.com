# Khyron Devs Flagship Site

Engineering-led digital products, bespoke web apps, and digital experiences. Built with Next.js 16, Tailwind CSS 4, and Motion.

## Tech Stack
- Framework: Next.js 16 (App Router)
- Styling: Tailwind CSS 4
- Animation: Motion (motion/react), GSAP (ScrollTrigger)
- Fonts: Geist & Geist Mono
- UI Primitives: Headless custom components + Radix UI

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Build & Production

To run a production build:
```bash
npm run build
npm start
```
